# Pre-existing work

The DYNEXA business concept predates ETHOnline 2026, and a separate experimental
prototype using WDK was built for Aleph 2026. No code, contracts, designs, assets,
configuration, prompts or technical components from that prototype were reused.
This implementation was created from an empty repository during ETHOnline 2026.

## What carried over

Only product lessons, not code:

- Web3 onboarding should feel like a normal Web2 login (no MetaMask, no seed phrase).
- A welcome reward creates an immediate emotional moment.
- Wallet balances must be readable by people who don't use crypto.
- Receipt scanning is an intuitive proof of purchase.
- The user needs to understand *why* a reward was approved or rejected.
- Businesses need budget control, campaign analytics and an audit trail.
- POS redemption has to be simple.
